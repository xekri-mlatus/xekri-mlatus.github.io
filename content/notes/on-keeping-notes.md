For years I kept notes that nobody read, including me. They sat in a folder,
perfectly private and perfectly useless.

<!--more-->

This site is the opposite experiment: write things down, put them where people
can see them, and improve them later.

## Why unfinished is fine

A blog post feels like it has to be finished. A note doesn't. It only has to be
true so far. That lowers the bar enough that I actually write things down, and
that matters more than polish.

Publishing also changes how I write. When a note might be read, I explain
things properly instead of leaving cryptic fragments for my future self — who,
it turns out, never understands them either.

## Three rules I try to follow

1. **One idea per note.** If a note is about two things, split it.
2. **Link generously.** A note that links to [other notes](/notes/) is more
   useful than one that stands alone.
3. **Revisit, don't restart.** Improving an old note beats writing a new one
   on the same topic.

This note will probably change too.
